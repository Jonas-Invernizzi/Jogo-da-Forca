# Jogo-da-Forca
O Jogo da Forca foi desenvolvido por Jonas Invernizzi durante o Ensino Médio Técnico em Informática, utilizando HTML, CSS e JavaScript. O jogo oferece uma experiência interativa, dinâmica e divertida, ideal para treinar raciocínio rápido e atenção.

As palavras são carregadas de uma API pública, garantindo variedade em cada partida. O HTML estrutura os elementos do jogo, o CSS define o visual e a interface, enquanto o JavaScript gerencia a lógica do jogo, atualização da palavra e verificação de vitória ou derrota.

Este projeto demonstra habilidades práticas em programação web, aplicação de lógica e integração com APIs, transformando conceitos aprendidos em sala de aula em um jogo educativo e envolvente.
